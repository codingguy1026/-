# 모여! (moyeo-play)

친구들과 가볍게 즐기는 그림 맞히기 파티게임 프로토타입입니다.

원본 프로토타입: https://moyeo-play.drawingguy1026.chatgpt.site

## 실행

```bash
npm install
npm run dev
```

## 빌드

```bash
npm run build
npm run preview
```

## 현재 포함된 기능

- 닉네임 입력
- 방 코드 생성 및 초대 링크 복사
- 방 코드 입장 UI
- 혼자 연습하기 제시어
- 모바일 반응형 랜딩 페이지

> 현재 방 생성/입장은 프론트엔드 프로토타입입니다. 실제 실시간 멀티플레이는 추후 WebSocket/Supabase Realtime 등의 백엔드 연결이 필요합니다.
